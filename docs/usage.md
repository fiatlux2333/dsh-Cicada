# 使用指南

适用版本：`dsh-cicada 0.1.2`，Windows / DeepSeek Harness **0.2.2-rc.1**，Node.js **24.9+**。使用前请阅读[安全与行为](safety.md)和[验证记录](verification.md)。

## 安装、升级与卸载

本仓库不提交预构建安装包。先按[开发与验证](development.md)生成 `dist/dsh-cicada-0.1.2.tgz`；若使用单独获得的包，应核对其来源及对应摘要，不假设旧构建的摘要适用于新包。

退出目标 profile 的宿主，从项目根目录运行：

```powershell
$package = (Resolve-Path '.\dist\dsh-cicada-0.1.2.tgz').Path
dsh plugin --profile desktop add $package
```

将 `desktop` 替换为实际 profile。重新启动该 profile，在「插件」中启用 `dsh-cicada`，打开详情或运行 `/cicada open`。

升级前先关闭自动触发并确认保存成功，再停用插件、退出宿主，移除旧包并添加新包：

```powershell
dsh plugin --profile desktop remove dsh-cicada
dsh plugin --profile desktop add $package
```

相同版本本地 tarball 也要先移除再添加，避免依赖缓存使旧代码继续运行。只卸载时执行 `remove` 即可；卸载不会自动删除加密领域数据。首次安装建立打卡基线，已有数据升级或重装不等同于首次安装，不应假设计时或模式已重置。

换包前运行 `pnpm compat:check`。已有真实预授权仍可能在换包启动后立即补执行。宿主已经升级导致旧插件无法打开、无法确认停止已保存时，不要直接启用新包或授予版本豁免；先保留停用状态并按[宿主升级方案](compatibility.md)完成隔离验证与安全恢复。监控不能在宿主关闭或插件被拒绝加载期间执行动作，沉默时长仍继续累计。

## 首次配置

1. 在总览核对演练模式、自动触发关闭和打卡基线。默认 Cookies 保留，事件日志清理关闭。
2. 在触发规则页设置四级阈值和动作。阈值必须为严格递增的有限正数，支持小数天；默认为 3、7、14、30 天。
3. 在动作配置页选择 Chrome/Edge，填写关键词、文件夹和软件目标，再保存。**未配置关键词意味着全量浏览数据清理，不代表禁用清理。** 不需要的动作应在触发规则中关闭。
4. 在假历史页选择六种人设之一并生成预览。预览不读取或写入真实浏览器。
5. 在总览执行「立即演练」，到运行日志检查计划和报告。演练不关闭浏览器，不执行破坏性动作。

分区草稿互相独立，切换页面不丢失。保存期间新增的编辑仍为未保存状态；失败或冲突不会被当作保存成功。需要放弃某分区草稿时使用该页「重新加载」，并确认放弃。不要把关闭整个宿主后仍保留草稿当作持久化保证。

卸载目标应填写软件的完整显示名称。非精确匹配仅接受唯一 Unicode 词边界匹配，`微信` 不会扩展成 `企业微信`；多个候选会拒绝执行。注册表没有候选时，仍只向 winget 传精确名称，不进行模糊卸载。

## 人工命令

| 命令              | 行为                                         |
| ----------------- | -------------------------------------------- |
| `/cicada status`  | 查看脱敏状态，不改变计时                     |
| `/cicada checkin` | 建立新打卡周期，重置沉默计时                 |
| `/cicada pause 4` | 暂停监控动作 4 小时；只支持 1、4、8、24 小时 |
| `/cicada resume`  | 提前结束暂停并评估到期等级                   |
| `/cicada drill`   | 排队演练，不授予真实执行权限                 |
| `/cicada open`    | 请求打开管理页                               |

只有打卡重置沉默时长。暂停、键鼠活动和关闭 Harness 都不停止累计；暂停结束或宿主重新启动后可能已经跨越多个等级。已开始动作不强行中断。

## 真实模式与预授权

真实执行应先在可恢复快照的 Windows 虚拟机验收。不要用重要文件、日常浏览器配置或无法恢复的软件试运行。

1. 保存目标、动作和阈值，检查执行范围。
2. 所有者在总览点击「切换真实模式」，阅读已保存配置的风险摘要，输入确认文字。切换模式后自动触发仍关闭。
3. 需要无人值守执行时，再单独点击「授权自动触发」并确认。到期后无需再次确认，重启后也可能立即补执行。
4. 需要立即人工执行时，使用动作配置页「全流程真实执行」。**该入口即使当前为演练模式也会真实执行，并重新执行全部启用等级**，不是只补未完成等级。

目标、动作或阈值等危险配置变化撤销预授权。关闭自动触发、暂停、打卡、配置版本变化和卸载插件取消未开始请求；已经开始的等级继续完成。取消的等级不会因此消耗真实资格，恢复后仍可能补执行。

模型只有 `cicada_status`、`cicada_preview_history`、`cicada_drill`，不能调用上述危险管理流程。真实模式和执行不能通过聊天中的简单布尔值确认。

## 停止与提醒

执行中可在总览点击「关闭自动触发」，或关闭触发规则页已启用的自动开关；真实模式下也可「切回演练」。这些入口不保存其他分区草稿，不依赖目标重新加密，取消未开始任务并撤销授权。

**停止设置若保存失败，本次宿主锁定后续动作，但磁盘设置可能仍处于启用状态。** 当前等级继续完成。修复存储问题后重试关闭自动触发或切回演练，成功保存前不要重启宿主。普通刷新、打卡或存储恢复不解除此运行时锁定。

每日提醒默认本地时间 21 点，可在触发规则页调整。关闭提醒会清除待提醒状态；同一天重新开启不重复已产生过的提醒，次日按配置时间恢复。关闭单次提示的「今日不再显示提醒」只作用于当前页面会话，不等同于禁用每日提醒。

## 导入旧版 Cicada

从动作配置页预览旧数据，固定只读访问旧版 `%APPDATA%\Cicada`。导入复制配置和打卡状态，不修改原文件，也不与旧程序共享运行文件。存在草稿时需要额外确认放弃，取消则保留修改。

导入强制演练、关闭自动触发并清除授权。旧版 `executed_levels` 无法证明演练或真实执行性质，必须在运行日志逐级核查：

| 结论         | 确认文字         | 结果                     |
| ------------ | ---------------- | ------------------------ |
| 仅为演练     | `已核查仅为演练` | 不占用真实执行资格       |
| 已有真实执行 | `已核查真实执行` | 当前周期不自动重试该等级 |

核查本身不执行动作。全部核查完成后才能真实执行，自动触发仍需重新授权。不能确定时保留待核查；打卡、重启或再次导入不会清除待核查等级。不要与旧程序同时运行真实自动动作。

## 常见问题

| 提示或现象             | 处理                                                                       |
| ---------------------- | -------------------------------------------------------------------------- |
| 敏感配置缺失或解密失败 | 在动作配置页人工恢复并保存目标，或导入有效副本；打卡、切回演练不能解除锁定 |
| 上次真实动作中断       | 先检查实际系统结果，再核查记录；不要把中断当作未执行而盲目重放             |
| 旧版执行记录性质不明   | 在运行日志逐级核查，不根据当前模式猜测历史执行结果                         |
| 停止设置尚未保存       | 修复存储后重试停止，成功前不要重启宿主                                     |
| 监控互斥锁失效         | 退出并重启原宿主；不要绕过锁或手工删除锁身份来接管                         |
| 只读实例               | 检查是否有其他宿主持锁；非 Windows 不启动监控                              |
| 保存提示版本冲突       | 保留所需输入，核对最新配置，再有意重新加载或编辑；不要误认为旧草稿已保存   |
| 浏览器无法正常关闭     | 保存浏览器工作并手动退出后检查；插件不会强制杀进程                         |
| 留下 `.cicada.*.bak`   | 这是失败动作的恢复备份，不要随意删除；先确认恢复需求                       |

仅支持本机管理，应绑定回环地址，不对外共享所有者凭据。其他限制见[安全与行为](safety.md)。
