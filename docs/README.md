## 阅读约定

- 使用指南和安全文档描述当前代码行为，不代表所有真实系统操作都已实测。
- 验证记录分别标明最新自动测试、历史集成证据和未验证行为；旧集成结果不自动覆盖后续构建。
- 示例中的 `desktop` 是可替换的 profile 名。修改其他 profile 前，应先确认实际宿主使用的 profile。
- 仓库不包含安装包、截图、测试宿主数据、恢复备份或凭据；这些本地文件不随 Git 提交。
- 任何演练测试都不得清理真实浏览器、粉碎用户文件、卸载实际软件或清除系统日志。
