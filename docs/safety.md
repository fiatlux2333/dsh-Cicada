# 安全与行为

适用版本：`dsh-cicada 0.1.2` / DeepSeek Harness **0.2.2-rc.1**。本文描述实现边界，实测范围请以[验证记录](verification.md)为准；安装和操作步骤见[使用指南](usage.md)。

> 真实预授权允许未来无人值守执行不可逆操作。演练不产生破坏性副作用，但不能证明真实系统操作一定成功。先在具有可恢复快照的虚拟机完成验收。

## 计时与执行

安装建立打卡基线；沉默时长使用墙上时钟减上次打卡时间。键鼠活动、暂停、关闭宿主不停止累计。启动立即评估，运行中每 60 秒评估，睡眠期间到期的定时器在恢复事件循环时继续评估。检测时钟回拨时锁定自动动作，待时钟追上或人工打卡后恢复。

宿主升级后旧插件被拒绝加载时，监控停止但沉默继续累计。本次兼容修复不重置领域数据、打卡或预授权；重新启用后可能立即补执行。升级前必须成功保存停止设置；无法确认停止已保存时，不应直接启用新包。不能用官方版本豁免或删除 `engines.dsh` 代替 SDK 迁移和隔离验收，详见[宿主升级方案](compatibility.md)。

真实自动动作必须先保存配置，再在图形界面切换真实模式并单独预授权。关闭自动触发、暂停、打卡、配置版本变化和插件卸载会取消尚未开始的请求。已经开始的等级不强行中断，以免造成半写数据库；其余等级仍可取消。每等级开始前先持久记录，执行串行。手工演练不占自动演练名额，所有演练均不占真实执行资格。

执行期间，总览的「关闭自动触发」、触发规则页关闭已启用的自动触发开关，以及真实模式下的「切回演练」仍可用。关闭自动触发走独立的所有者 Remote，不提交任何分区草稿，也不依赖 DPAPI 重加密；操作成功后取消未开始任务并撤销预授权，正在执行的等级继续完成。其他配置仍禁止在动作执行期间保存。恢复真实自动触发需再次人工授权，取消的等级保留后续执行资格。

停止请求在等待持久化前先锁定本次宿主的后续执行。若停止设置写入失败，接口报告失败，不把内存保护冒充持久化成功；当前动作可完成，但自动队列和人工全流程队列都不能继续启动。普通 tick、打卡或存储恢复不解除锁定，需显式重试关闭自动触发或切回演练并成功保存。成功保存前不要重启宿主，磁盘中的旧预授权可能仍存在。

宿主崩溃后，`started` 转 `interrupted`，阻止进一步真实自动执行，直到人工检查。人工标记已核查后，该等级仍保持不自动重试。失败等级也不自动重试。仍需有意执行时，使用图形界面的全流程真实执行，注意它会重新执行全部启用等级。

Windows 当前用户级命名互斥锁防止多个宿主重复处理。第二实例只读，不接管监控，也不会实时同步第一实例内存视图。所有持久化入口都检查锁；检测到锁失效后，本实例永久停止写入，不写回动作完成结果或关闭时的旧快照，也不启动下一等级。已持久化的 `started` 交由下一个所有者恢复为 `interrupted`，需人工核查；失效实例需重启宿主。不要将多个宿主指向同一数据目录后手工绕过互斥锁。

固定注册表位置 `HKCU\Software\DeepSeek Harness\Cicada` 的 `MonitorOwner` 仅记录持锁宿主 PID、启动时间和随机租约 ID，不含目标或关键词。正常卸载且在途动作、写入结束后释放身份；辅助进程异常退出时保留身份，旧宿主仍存活则拒绝接管，避免尚未完成的异步存储写入与新所有者交叉。旧宿主退出后可接管，PID 启动时间用于防止 PID 复用误判。此保护失败关闭，辅助进程异常时仅重载插件不足以恢复，需退出并重启原宿主。

## 数据保护

使用官方 `storageDomain` 保存版本化配置、时间、授权哈希与报告。文件夹、软件名、关键词整体通过 CurrentUser DPAPI 加密，首次安装的空目标也必须加密成功才建立持久基线。解密、结构校验或持久化失败均失败关闭，不转换为空关键词的全量清理。已有记录的空密文（包括旧版未保存目标的空基线）一律视为缺失，不以是否存在自动授权为条件。此时所有真实确认和自动动作锁定，打卡或切回演练不能清除此锁定；需在动作配置页人工恢复并保存敏感目标，或导入有效副本，再重新授权。导入固定读取旧版 `%APPDATA%\Cicada`，只复制，不改原文件；导入强制演练、关闭自动触发、清除授权。

只有所有者 Remote 可以读取明文目标。模型工具只获得脱敏状态、合成历史与演练排队结果，不复用管理接口。配置、日志与模型消息均不应记录原始目标。界面的敏感目标不写浏览器 localStorage，分区草稿只保存在当前页面进程内存中。

切换模式、预授权及人工执行不提交或丢弃其他分区草稿。只有已保存配置未发生冲突时，草稿版本才随本次模式操作更新；外部配置冲突仍拒绝保存。导入会替换已保存配置，存在未保存草稿时必须额外确认放弃草稿，取消则保留全部修改。

保存期间可以继续编辑。保存响应只清除与提交快照一致的草稿；期间新增的修改保留未保存标记，并可用提交后的版本继续保存。关闭自动触发或切回演练会同时清除草稿中的自动触发开启值，避免随后保存其他修改时意外重新开启。

刷新使用请求顺序及配置版本保护，过期响应不回退状态或草稿版本，过期失败不覆盖当前连接结果。每日提醒关闭后清除待提醒状态，读取时也抑制旧版残留；当日已提醒标记保留，同日重新启用不重复提醒，次日按配置时间恢复。

## 旧版记录核查

旧版 `executed_levels` 没有执行模式或完成证据，当前 `dry_run` 也不能证明历史动作性质。导入时这些等级均保留为待核查，不直接消耗真实资格，也不立即重放；旧插件数据里已有的 `legacyLevels` 同样按待核查处理。

在「运行日志」逐级核查：选择「仅为演练」并输入对应确认文字后，该等级不消耗真实执行资格；选择「已有真实执行」后，该等级在当前周期不再自动重试。核查会保存带 `legacy` 来源的报告，关闭自动触发并撤销授权，本身不执行任何动作。完成全部核查后才能进入真实模式、预授权或人工真实执行；仍需主动授权自动执行。不能确定性质时保留待核查状态，仍可手动演练。

待核查记录跨重启、打卡、切回演练和再次导入保留，不因重置计时或导入无等级文件而被清除。核查检查所有者身份、等级、模式、确认文字及状态版本；冲突或保存失败不会删除待核查记录。只登记人工结论，不读取或修改旧版文件，不把当前模式猜测为旧执行证据。

## 系统边界

Chrome/Edge 使用 TypeScript 与 Node SQLite。先请求浏览器正常退出，仍运行则拒绝写入，不强制杀进程。每次写入独立 SQLite 在线备份、事务、WAL checkpoint 和 VACUUM；失败保留本次备份，成功仅销毁本次备份。不要手工删除其他 `.cicada.*.bak`，它们可能是待恢复数据。

定向清理在删除访问关联前记录受影响聚类，删除因此失去全部访问的聚类及关键词；混合聚类保留无关访问，仅清空命中关键词的标签、原始标签，并删除命中关键词的条目。这些操作与访问清理、假历史写入共用事务，后续写入失败时一并回滚。缺失可选表或列不会扩大清理范围；这不是对任意未来 Chromium 数据结构的兼容承诺。

文件目标拒绝根目录、UNC、系统目录、用户数据根、Harness 安装和数据目录、插件目录及相关上级目录。检查路径重解析点和硬链接，硬链接仅移除链接，不覆写共享数据。文件夹链接不跟随。检查并不能消除有恶意并发进程时全部路径替换竞态；不要将攻击者可写目录用作真实目标。SSD、快照、备份、云同步和文件系统日志均不在物理擦除保证内。

Windows 辅助脚本仅固定枚举操作，从 stdin 接收严格输入，不拼接用户提供的 shell 命令、不自动提权。卸载匹配采用精确名称或唯一 Unicode 词边界，边界包括字母、数字、组合字符和连接标点，不将中文前后缀当作分隔符；歧义拒绝，拒绝 shell 解释器卸载入口，未注册软件仅向 winget 传精确名称。Windows 痕迹动作包括最近项目、跳转列表、缩略图缓存、预读、RunMRU、TypedPaths、DNS 缓存与回收站；可能需要权限，部分失败会报告失败。系统事件仅 Application/System，默认关闭。

预授权等同于授权未来不可逆操作。仅在快照虚拟机验证后启用；不要在有未保存浏览器工作或重要数据的环境试用真实模式。
