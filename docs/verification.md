### 业务覆盖

- 状态机：离线跨级、重启防重放、暂停到期、时钟回拨、并发 tick、周期及版本绑定、排队取消。
- 故障边界：开始前持久化、执行中崩溃、完成写入失败、取消写入失败仍等待当前动作、旧所有者不得覆盖新打卡。
- 锁与密文：失锁禁止提交，加密等待中失锁，首次加密失败不建立基线，缺失密文锁定真实动作，DPAPI 失败替身。
- 系统替身：SQLite 事务回滚、恢复备份、浏览器关联表、假历史、路径/硬链接/目录链接保护、卸载匹配。
- 旧版数据：待核查等级、演练恢复资格、真实不重放、旧数据升级、跨重启/打卡/再次导入、核查冲突及保存失败保护。
- 最近新增：自动和人工真实队列分别在停止/切回演练写入失败后只完成当前等级，存储恢复与 tick 不解除锁定，显式重试保存后仍未授权，重新授权只接续取消等级。
- 提醒：关闭已产生的提醒后 tick 和重启不再提示，同日重新开启不重复，次日恢复；旧版残留在只读实例被抑制，在可写实例持久修复。

### 接口与界面覆盖

官方 Gateway 和注册表进程内集成测试加载生成的严格约定，拒绝额外参数、错误类型、未知方法、无效确认及非所有者。`stopAutomation` 与 `resolveLegacy` 覆盖严格输入、所有者限制和读写往返；模型工具仍只有约定的三项。最近修复未改变公开 Remote 方法签名。

UI 覆盖保存失败、跨分区草稿、各类确认后保留草稿、配置冲突、导入放弃草稿确认、保存响应未返回时继续编辑、忙碌期间独立停止、旧记录两类核查结论和窄屏弹窗。最近新增乱序回归验证旧刷新不得回退配置及草稿版本、旧失败不误报当前连接故障、同配置版本的旧状态不覆盖新状态。

确认成功使用纯浏览器响应替身，不调用 Host 或真实系统动作。普通预览仍禁止确认真实执行。截图输出到本地 `artifacts/ui/`，不提交仓库。

### 测试安全边界

业务自动测试使用临时目录、合成浏览器数据库、内存时钟与系统动作替身。未清理真实浏览器、粉碎用户文件、卸载实际软件或清除系统日志。停止写入失败的保护是运行时锁定，不冒充持久化成功，必须重试成功后再重启宿主。
